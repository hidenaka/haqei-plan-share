通しで見たときの絵の流れ

  • 幕1：休む動作が途中で止まっている手元 → 縁まで水が来ている器（＝この回の全体像を先に一度見せる）
  • 幕2：朝が来ている机 → 橋の間の一本の線 → 節で折れた竹 → 一つだけ空になった器
  • 幕3：水が落ちる沢 → 縁で止まる水 → 折られた和紙（肯定と禁止）→ 内側の戸と外の門 → 同じ錘で傾きが逆の天秤 → 段を降りる水（芯）

  • 幕5：六段の階段を下から。手を離しても流れが変わらない堰（本体）→ 一本だけ緩んだ縄 → 刻みの入った升
  • 幕6：折れた竹と若い竹 → 冒頭の器に戻り、刻みが一本だけ増えている（ここでループ）
