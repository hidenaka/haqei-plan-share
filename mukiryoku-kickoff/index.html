自分を学習する自己改善AI「手札」｜調査と設計案 v12

やる気はいらない。手札を1枚ずつ試すと、AIが「自分」を覚えていく

「やるべきこと（仕事）はある。それ以外の自由時間をどう使えばいいか決まっていない」——Obsidian が空のまま終わる人のための、まず自分用の自己改善AI。科学的・非科学的を問わず「いろんな人のやり方」を手札にして試し、変わればいい。研究と、別AI 12ラウンドのダメ出しをもとに設計しました。あなたの隔日勤務（出番・明け・公休）に合わせてあります。最後の「あなたが決めること」だけ答えてください。

3行でいうと

  1. 動けないのは根性の問題ではなく、脳の「割に合わない」計算＋目標がない＋1回サボると全部やめる、の3重苦。
  2. 効くのは「やる気を出す」ことではなく、自分の違和感から出た方向の「本物のミニ版（2分）」をいつもの行動にくっつけ、できたものの山を見せ、サボってもゼロにしないこと。
  3. 頭脳は Mac の Claude Code（サブスク内で正規）、手足は iPhone、橋は iCloud。本人の隔日勤務に合わせ、「毎日同じ時刻」をやめて「起きた」を押した日だけ触れる日にした（v12）。最終判定は3観点 Yes・条件付きGO（条件反映済み）。

01全体を1枚で

左が「なぜ動けないか」、右が「どう乗り越えるか」。真ん中がこのアプリの役割です。

ひとことで: 今のアプリは「目標を決めて、毎日続けて、途切れたらリセット」。それは一番できない人を一番早く追い出す設計です。逆をやります。

02なぜ動けないのか（4つ）

研究で分かっている「動けない人」の中身。全部、性格ではなく仕組みの話です。

⚖️

脳の天秤が「しんどい」に傾く

脳は毎回「手間」と「ごほうび」を天秤にかけます。無気力の人は、ごほうびが同じでも「手間」側が重く見える（脳科学で確認済み）。

だから → 手間をほぼゼロにする
🧭

目標がない＝地図に目的地がない

「やる気を出す」系の介入は、目標がない人にはほぼ効かない（効果ほぼゼロ）。自分らしい目標は「試して、少し良かった」を集めた後に立ち上がる。

だから → 先に小さく試す。目標は後
🔄

「やる気→行動」は逆

気分が乗るのを待つと永遠に来ない。先に体を動かすと、後から気分がついてくる（うつ治療でも一番効く方法の1つ）。

だから → 行動を先に、報酬をすぐに
⛓️

1日サボると「もういいや」

1回の失敗を「自分はダメだ」と解釈して全部やめる。連続記録（ストリーク）はこれを悪化させる。実は1日抜けても習慣には影響しない。

だから → ゼロに戻さない。戻ってきたら褒める

04今あるアプリの「やってはいけない5つ」

習慣アプリ・自己啓発アプリが、まさにこの層を追い出している設計。

よくある設計何が起きるかこのアプリでは
❌ 最初に「目標を設定してください」目標がない人は最初の画面で詰む✅ 目標は聞かない。「今日の2分」から始まる
❌ 連続記録（ストリーク）とリセット1日抜け → 怒って離脱✅ 累計と「戻ってきた回数」だけ
❌ 毎日のチェックリストリストが「義務」になり、リスト自体が重荷に✅ 1日1つだけ。増やさない
❌ やる気を出させる名言・通知無気力の人には効かない。むしろ反発✅ 通知は「きっかけの時」に1回だけ。中身は行動の指示のみ
❌ 記録が目的化記録して満足、行動は増えない✅ 記録はワンタップ。見返すのは「少し良かった」の集まりだけ

05作りたい仕組み（v10）— 頭脳は Mac の Claude Code、手足は iPhone

サブスクの Claude で使えるのは「Claude Code と claude.ai」だけ（他アプリからの流用は規約違反・2026年1月から遮断）。だから頭脳を Mac の Claude Code に置き、iPhone は手足、iCloud のフォルダが橋。OpenAI の契約は不要（ChatGPT Plus にも API は付かない）。

頭脳（Mac）
🧠

Claude Code のスキル 1本（サブスク内・自動実行）。本の一節→手札、判定→集計＋見立て、今日の実験＋1問、1行返事。1週目から Claude Code 単体で使える（スマホのリモートからも）

橋（iCloud）
🌉

iPhone が「答え・判定・本の写真」を置く → Mac が読んで「返事・手札・見立て」を置く。返事は翌日、次に開いた時（夜書いて翌日の夜に一言）

手足（iPhone）
📱

実験層（行動×手札・3回で次へ・戻す装置）＋今日の1問＋集計。AI が落ちても動く

枠は大きく — 「いろんな人のやり方」の棚

📚

出典は8種、全部同じ棚

研究者／ビジネス書の経験談／思想・宗教・武道／占い・易経・スピリチュアル／有名人の習慣／民間の知恵／ネットの流行／自分で作った。根拠の種類はタグで見せるだけ。載せる・載せないの門番にしない。

📸

本から手札を作る（主役）

読んだ本の一節を写真・貼り付けで入れる → AI が「この人のやり方」を 1〜3 枚の手札にする → 採用。30ページで止まった本でも1節あれば手札になる。

🕰️

行動の枠も広い

時間帯は朝・日中・帰宅後・寝る前。長さは30秒・2分・10分（2分は床で上限じゃない）。「寝る前に達成した場面を想像する」のような本のやり方を、歪めずそのまま試せる。

🔮

見立て（占い調）OK

AI は初日から「あなたは『整える』系。今週はこの3枚」と言い切ってよい。縛りは1つ：同じ見立てを3回試すまで次を出さない。数字（n）はタップすれば見える。

いい加減でいいところいい加減にしないところ（これだけ）
科学的根拠／著者の主張との一致／自分モデルの正確さ／手札の数（数千枚でよい）／実名・書名（自分用）「変わったか」を測る: 週の完了数・戻ってきた回数・自分で変えた回数・本から作った手札をやり切った枚数。害の門番: 自罰・恥・連続記録・診断は入れない、危機的内容は AI に触らせない。規約の線: 配布した瞬間に Claude Code 経路は使えない（API 課金に切替）

核になる発想（v10）: 世の中はいい加減でもうまくいっている人がいる。だから手札は科学も占いも同じ棚に置き、本の一節から作れるようにし、AI は占い調で背中を押してよい。いい加減にしないのは「行動が変わったかを測る」「害を入れない」「規約の線」の3つだけ。

実装の順番: ① Claude Code スキル `tefuda-brain`（1週・今週から使える）→ ② iPhone アプリ（8〜9週・Developer Program 加入後）→ ③ iCloud 橋（2週・配管が9割）→ ④ 3枚生成（1週）。API 費用ゼロ（サブスク内）。Developer Program ¥15,000/年 は iPhone アプリ段階で必要。

05b あなたの生活リズムに同期（v12）— 「起きた」で今日が決まる

出番は朝7時〜翌3時、合間は触れるが乗務後は触れない。明けは起きたら触れる。翌日出番なら早寝。公休は自分で決める。だから「毎日同じ時刻に通知」を捨てました。

出番の日
🚕

何も鳴らない。ロック画面のウィジェットに「今日の30秒札」が1枚あるだけ（例: 抵抗に名前をつける・良かったこと1タップ）。合間に1タップ。乗務後は何も出ない。サボり扱いにもならない

明けの日
🛏️

起きたらウィジェットの「起きた」を1タップ。その瞬間から +1時間・+4時間・19時に札が来る（21時以降は来ない＝早寝）。最初の通知に「明日は？ 出番／公休」ボタン。答えなければ出番扱い

公休の日
🌤️

「起きた」を押せば一日使える。「寝る前」型の札もこの日だけ

予測が外れた日
🔁

「起きた」を押した日＝触れる日、押さない日＝出番。だからカレンダーや隔勤パターンが外れても壊れない。予測は「起きた？」の1通をどの日に出すかにだけ使う

戻る入口
🚪

止まっても、ウィジェットの「起きた」は常にそこにある。押せば「おかえり」で続きから

日触れる時間札通知
出番合間だけ30秒札のみ（車内で1タップ・5枚）なし（ウィジェット）
明け起きてから2分／10分「起きた」+1h・+4h・19時。21時以降なし
公休一日2分／10分・寝る前型もOK本人が選んだ最大2枠
明け（翌日公休）夜も寝る前型OK21時枠も可

日タイプの決め方: 実測（「起きた」／「今日は出番」／「明日は？」の答え／タクシー日報の乗務開始・後で）が常に予測（カレンダー・隔勤パターン）に勝つ。出番の完了は山に積むだけで、3枚選び・1問は次の触れる日に持ち越す（客待ち中に飛び出させない）。ダメ出し: 当事者役「30秒札が1枚もない・明日が出番か分からない」、実装役「予測が外れると通知が沈黙する」→ 「起きた」方式で解決。最終判定 3観点 Yes。

06あなたが決めること

「A・A・A」の3文字でOK。答えをもらったら設計書 → 実装計画 → 実装へ進みます。

A. はい、頭脳スキルからおすすめ

B. もう1周ダメ出し

A. iPhone アプリの段階で入るおすすめ

B. 今すぐ入る

並行して iPhone 側も始めるなら。

C. 入らない

Q3カレンダーはどれ？ 出番・公休はどう書いてある？

A. 「起きた」だけ

カレンダーなし。起きたら1タップで今日の枠が決まる。

B. カレンダーを読む＋「起きた」本人指示で確定

カレンダーで出番・公休を判定（明日は？を聞かない）。「起きた」は起床時刻の確定用。教えてほしいのは「どのカレンダーで、出番・公休をどう書いているか」。

C. 日報アプリの乗務開始で自動判定

タクシー日報の記録開始＝出番確定（ショートカット連携）。後回しでも可。

確定したもの: サブスク内の Claude Code を頭脳に／占い調 OK／科学・非科学を問わず同じ棚／自分用は実名・書名 OK／隔日勤務に同期（出番は中立・明けは起きたら）／最初の利用者＝あなた。

まだコードは書いていません。 Q1〜Q3 の答えをもらってから、設計書 → 実装計画 → 実装の順で進めます。

結論

  1. Obsidian の逆を作る: 構造を作らせない。本の一節を入れれば手札になり、「やった」1タップと「1問の答え」で自分モデルが溜まる。
  2. 手札＝研究も、ビジネス書の「俺はこうやってきた」も、占い・易経も、同じ棚。本の一節を写真で入れると手札になる。3回試したら次へ。AI は「見立て」（占い調）を言ってよく、数字は端末が数える。成功の物差しは「行動が変わったか」だけ。
  3. 決めてほしいのは3つ: 頭脳スキルから始めてよいか・Developer Program にいつ入るか・「起きた」1タップ方式でよいか。
