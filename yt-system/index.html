1. アイデア選定システム — 何を作るか決める4つのフィルタ

「思いついた順」をやめて、次の4つを全部通ったものだけ作ります。1つでも欠けたら捨てる。

フィルタ1：痛みが「先週その行動をした実在の人」を3人挙げられるか

挙げられないなら、それは思いついた痛みであって実在する痛みではない。あなたのrejections台帳にある「連絡先を心の中で並べ替える」が典型で、機知に富んでいるが誰もやっていません。
→ この基準は既にあなたの企画工程に入っています。維持してください。

フィルタ2：卦の側に「検証できて、意外な、構造的な事実」が1つあるか

これがあなたの唯一の参入障壁です。感想は誰でも言える。「3000年前の本の同じページに、正反対の判定が並んで書いてある」は誰にも真似できない。
条件：①db本文で逐語確認できる ②視聴者の常識と逆 ③1行で言える。
例：節＝「戸を出ない＝咎なし／門を出ない＝凶」（一字違いで正反対）。大畜＝「蓄えよ」と書いた同じ場所に「家で食べるな」。

フィルタ3：作品の中に、その構造が「絵で見える一場面」があるか

あらすじではなく一場面。視聴者が既に見て覚えている絵。ここが弱いと「無理やりくっつけた」になります（あなたが第50話で指摘したのが、まさにこれです）。

フィルタ4：作品名で年間検索がある大型IPか

あなたの検索流入は1.3%。検索は当面あきらめるのが正解ですが、大型IPはショートフィードの初速そのものが違います。実測：ワンパンマン1,511／四月は君の嘘1,248／五等分1,051 に対し、卦の解説寄りのショートは0〜数百。

2. フック — 最初の3秒と、9秒の崖

あなたの本編は21本中21本が20秒以内に最大離脱、中央値9秒。これは「つまらない」のサインではなく、9秒地点で"約束"が確認できないサインです。

3層フック（ショート／ロング共通）

層秒やること禁止
①止める0-3秒視聴者の生活の一場面を断定で。主語は「あなた」ではなく現象挨拶・チャンネル名・「今日は〜の話」・概念語（衝撃・構造・本質）
②値札3-9秒この動画を最後まで見ると何が手に入るかを具体物で言う「解説します」（値札になっていない）
③物証の予告9-20秒「反論できない一枚がある」と言い、まだ見せない先に見せる／予告しっぱなしで回収しない
②が今いちばん抜けています。 あなたの冒頭は「痛みの断言→作品→ループ3本」で、痛みは強いのに値札がない。視聴者は「わかる、でも自分に何が残る?」で降ります。値札の例：「今日持って帰ってもらうのは、"我慢の種類を見分ける4つ目の段"です」——具体物を1つ、名前をつけて先に渡す。

3. タイトル — あなたのA/Bが既に殺した定説

次の2つは、あなたの実測で否定済みです。私も採用しません。
  • 「作品名を先頭に置くとCTRが上がる」→ 反証（H1: 0.95% vs 0.94%）
  • 「サムネA/Bで大きく変わる」→ no_lift（H-CTR-1: 4本ともCTR±0.1pt）
つまりあなたの規模では、タイトルとサムネの小改善はCTRを動かしません。動かすのは「誰に配られるか」であって、配られた後の勝率ではない。ここに時間を使うのは今は損です。

それでも守る3条件

  1. 痛みの一文＝冒頭1行目＝share_line を完全に一致させる（3つが同じ一つの約束）。これは現行H58の型で正しい。
  2. 作品名は入れる（CTRのためでなく、検索と関連動画の分母のため）。効き方が違うので混同しない。
  3. 結末を書かない。「始まりの矛盾」だけ置く。

4. サムネ — 3秒で「これは自分の話だ」

CTRが動かない以上、サムネの仕事はクリック率ではなく"誤クリックを減らすこと"に置き換えます。間違って来た人は9秒で降り、それがアルゴリズムへの悪い信号になります。

要素ルール理由
題字主語＋述語で意味が立つ一文（単語の羅列にしない）単語は「ジャンル」を伝えるが、文は「自分の状態」を伝える
文字数10〜14字を2行まで。360px幅で読めること実寸モックで確認（既存工程どおり）
絵未解決を1点だけ仕込む（「なぜ山の中に金が?」）説明済みの絵はクリックの理由にならない
明るさ平均輝度70以上暗いサムネはフィードで沈む
禁止顔・作品の意匠・易経ワード法務方針＋視聴者語で書く原則

幕尺役割変更点

維持テクニック（この番組で実際に効くもの）

  • 物証の遅延：六爻図は「見せる」と予告してから2分以上おいて出す。予告→回収の距離が長いほど残る。
  • 段に名前をつける：処方箋の6段を「一段目」ではなく「借りとして数えるのをやめる段」のように名詞化する。名前がついた瞬間、視聴者は持ち帰れる物として数え始める（＝離脱しにくくなる）。
  • 同じ場面へ戻る：刃も余韻も、冒頭で描いた一場面の中で返す。別の場面へ飛ぶと「別の話」に見えて降りられる。
  • 予告の張り逃げをしない：張った予告は必ず名指しで回収（「さっき見せると言った一枚がこれです」）。

8. CTA — ここが最大の穴

あなたのショートは、登録する理由を一度も言っていません。 「全64話 連載中」のバッジはジャンルの説明であって、登録の理由ではありません。0.034%はその結果です。

新しいCTA設計（ショート専用・3つだけ）

入れるものなぜ効くか
①未完の宣言最後の5秒で「この卦の続き（次に何が起きるか）は、この動画では言いません」と明言する「見終わった」を「まだ途中」に変える。人は完結した話には登録しない
②固有名の約束「次は◯◯（作品名）で、同じことをやります」と1本だけ名指しする「シリーズです」は抽象。「次は進撃でやる」は予定。予定にだけ人は付いてくる
③在庫の提示「これで50個目です」と数を言う今日の1本ではなく棚を見せる。登録は棚に対して押される

ロングのCTAは今のまま（ループ設計・終盤カードなし）でよい。ロングは既に0.549%で機能しています。

上のシステムを全部通した1本。時をかける少女（紺野真琴）× 臨（りん・第19卦）。作中事実はja.wikipediaで確認済み、卦は db/hexagrams.json の逐語です。

なぜこの組み合わせが選ばれたか（4フィルタの通過）

  1. 実在検証：「残り回数が見えているのに、つまらないことに使ってしまう」——スマホのバッテリー残量を見ながら無意味にスクロールする／有給の残日数を知りながら消化しない／賞味期限を確認してから冷蔵庫に戻す。3つとも先週誰かがやっている。
  2. 卦の意外な事実：臨は最上級の吉卦（元亨利貞）なのに、その卦辞の中に 「八月に至りて凶あり」——良い時期の説明文の中に、終わりの日付が書き込まれている。しかも凶と判定される唯一の爻（三爻）は「うまくいっていて気が緩み、雑に扱う」段。
  3. 絵で見える一場面：真琴の左腕に残り回数が2桁の数字で浮かぶ。「残りが見えている」が literally 画になっている稀有な作品。
  4. 大型IP：細田守／2006年／国民的知名度。

10. なぜ効くのか（設計意図の分析）

仕掛け効く相手なぜ
0-3秒の「充電18%」スクロール中の親指ショートフィードは絵と1文しか判断材料がない。誰もが今日やった行動を名指しすると、指が止まる
3-9秒の値札9秒の崖あなたの最大離脱点はここ。「共感」だけでは残らない。持ち帰れる物の名前を先に渡すと、取りに行くために残る
「吉の卦の中に凶の日付」賢い視聴者感想は代替可能、引用は代替不能。この1点があなたの参入障壁
段に名前をつける処方箋の離脱「一段目」は手順、「雑になる段」は持ち物。人は持ち物を数え終わるまで離れない
未完の宣言登録ボタン完結した話には登録しない。「言いません」は最も強い登録理由
次回作品の名指し登録ボタン「全64話」は棚の説明。「次は あの花」は予定。人は予定に付いてくる

11. 計測 — 何をもって「効いた」とするか

再生数で判定しない。 あなたの規模では1本の再生数は運で±3倍動きます。判定は必ず率と本数で。
施策主指標合格ライン判定
ショート新CTA（3点）d7の subs/1,000views0.34 → 1.5以上6本たまった時点。5本以上で再現していること
冒頭の値札ロング30秒残存42.9% → 55%以上4本の中央値
段の名前化幕5帯の離脱率現行比0.7倍以下scene-retention

反証条件を先に書いておきます：ショート6本で subs/1,000views が 0.7 未満なら、CTAは効かなかったと結論し、次は「ショートの尺を2〜3分に伸ばす（変換はロング寄りになる仮説）」へ移る。差が出なかったことを「効果なし」と書かない——n=6の検出力では ±100% 未満の効果は見えません。
